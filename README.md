To install this code into the VEX V5 brain, get the latest commit by pressing the green or blue code button at the top right and then click on download zip.

Make sure you have Visual Studios Code with the PROS (Perdue Robotics Operating System) extention which should also include the Vex and C++ extention.

Go-to file on top left and select the downloaded folder AFTER UNZIPPING.

Click on the PROS Icon on the left and then press Build and upload whilst the computer is plugged into the brain (THAT IS ON VIA A BATTERY) that you want programed. Cleaning is optional but is good to clear cache.
